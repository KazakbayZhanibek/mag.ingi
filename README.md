# ENERGY STROY LTD

Статический сайт для GitHub Pages. Сборка и зависимости не требуются.

## Локальный запуск

Из папки проекта: `py -m http.server 4174 --bind 127.0.0.1`.
Открыть http://127.0.0.1:4174/.

## Публикация

Публикуется корень ветки main в GitHub Pages:
https://kazakbayzhanibek.github.io/mag.ingi/
После изменений CSS/JS обновить версии ссылок в index.html и privacy.html.
Перед коммитом: `node --check script.js`, `git diff --check`.
Проверить ширины 320, 390, 820 и 1440 px, меню, якоря, карту и валидацию формы.

## Форма

Нативный POST отправляет поля в существующую Google Form и открывает её
страницу подтверждения. Сайт не имитирует успешную отправку и не использует
непроверяемый fetch no-cors. Без JavaScript сохраняется стандартная HTML-валидация.
Идентификаторы полей entry.* и адрес формы должны соответствовать форме владельца.
После изменения вопросов Google Form перепроверить их. Не менять владельца
формы и не отправлять тестовые заявки без согласования.
Владелец должен проверить получение пробной заявки и включить уведомления
о новых ответах в своей Google Form.

## Данные и изображения

Контактный телефон и адрес используются в index.html, privacy.html и JSON-LD.
Логотип: energy-stroy-logo-v2.png. Фотография в первом экране иллюстративная,
не является фотографией выполненного проекта. Нерелевантные фотографии услуг убраны.
Карта загружается с Яндекс Карт. Без её загрузки остаётся ссылка «Открыть в картах».

Перед окончательным наполнением нужны подтверждённые владельцем:

- принадлежность лицензий, год начала работы и список клиентов после смены названия;
- корпоративная почта;
- реальные фотографии и описания проектов, разрешённые к публикации;
- проверка владельцем политики обработки персональных данных.

Не добавлять вымышленные отзывы, сроки, гарантии или показатели.
